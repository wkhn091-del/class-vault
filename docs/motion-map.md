# Motion map — המתיבתא

רמת תנועה: **כיף ללמוד** · צבע בכל האתר (נייבי / כחול / פליז / קרם) · בלי 3D

| רגע | מה קורה |
|---|---|
| ScrollProgress | קו brass→navy בראש |
| Hero | כתמים נושמים + CTA |
| Marquee | מקצועות רצים |
| **דלתות מקצוע** | 3–4 כניסות צבעוניות לתיקיות אמיתיות |
| **נוסף לאחרונה** | רצועת רעננות |
| איך לומדים | Reveal + קו שלבים צבעוני |
| מונים | Counter על רקע נייבי |
| ארכיון | רקע כחול־קרם + FolderCard |
| תיקייה פנימית | שטיפת צבע לפי לשונית |
| פוטר | נייבי מלא |

רצף פסיכולוגי: מותג → סקרנות → **דלתות (פחות בחירה)** → רעננות → בהירות → הוכחה → ארכיון → טיפ → סגירה
